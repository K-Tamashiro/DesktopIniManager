# DesktopIniManager v1.3.0

This release expands DesktopIniManager from a folder-icon utility into a faster project-navigation and scoped code-search tool for large Windows development drives.

## Highlights

- Added non-modal Scoped Code Search for selected folders and projects.
- Added string, regular-expression, case-sensitive, and whole-word search modes.
- Added built-in language profiles and a customizable plain-text extension profile.
- Added grouped, progressively displayed Grep results with external-editor navigation.
- Added file list, small-icon, and large-icon views for the selected folder.
- Added file-name filtering, file icons, and double-click editor launch.
- Improved fast NTFS indexing and reused a single path index across folder, project, and solution analysis.
- Improved Visual Studio solution mapping and physical/logical project-tree handling.
- Added hide/unhide actions and safer visible-row-only selection behavior.
- Refined light/dark theme styling, icon buttons, scrollbars, spacing, and window layouts.
- Simplified and expanded the bundled `mftree` command-line tool.

## Requirements

- Windows 10 or Windows 11, x64
- .NET Framework 4.8

## Download

Download `DesktopIniManager-v1.3.0-win-x64.zip`, extract it to a writable folder, and run `DesktopIniManager.exe`.

The archive also includes `mftree.exe`, `FastVolumeIndex.Core.dll`, the bundled icon assets, and the README.
