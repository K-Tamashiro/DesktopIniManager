DesktopIniManager v3.6.0
==========================

■ ソフトウェア名

DesktopIniManager


■ バージョン

3.6.0


■ ソフトウェア種別

フリーソフト


■ 概要

DesktopIniManagerは、大規模なフォルダーやVisual Studioソリューションを対象として、
フォルダー走査、ファイル検索、Grep、フォルダー比較・同期などを行うWindows用ツールです。

大量のファイルを含む開発環境から、必要なフォルダーやファイルを素早く探し、
比較・確認・同期することを目的としています。


■ 主な機能

・フォルダー階層の高速走査
・ファイル名による検索
・チェックしたフォルダー配下を対象とするスコープ検索
・Visual Studioソリューションの解析
・Grep検索
・Grep検索履歴のタブ管理
・Source / Targetによるフォルダー比較
・差分ファイル、片側のみのファイル、同一ファイルの確認
・Source / Target間のファイル同期
・比較履歴のタブ管理
・選択ファイルを相対パス構造を維持したままZIP保存
・フォルダー／ファイルのドラッグアウト
・比較結果からのドラッグアウト
・Grep結果からのファイル操作
・外部エディターとの連携
・キーボードによる検索結果、差分結果の移動
・Visual Studioソリューションのビルド支援


■ 動作環境

対応OS：
Windows 11 64bit

必要環境：
.NET 10 Desktop Runtime

本ソフトウェアは64bit版Windows向けとして提供しています。


■ インストール

インストーラーは使用しません。

配布ZIPファイルを任意のフォルダーへ展開してください。

展開後、

DesktopIniManager.exe

を実行してください。


■ アンインストール

DesktopIniManagerを終了した後、
展開したDesktopIniManagerのフォルダーを削除してください。

Windowsのシステムフォルダーへファイルをインストールする方式ではありません。


■ 基本的な使い方

1. メイン画面で検索対象となるルートフォルダーを選択します。

2. フォルダー階層を表示し、目的のフォルダーやファイルを確認します。

3. 検索文字列を入力すると、対象ルートまたはチェックしたフォルダー配下から
   ファイルを検索できます。

4. Grep画面では、ファイル内容を対象とした文字列検索を行えます。

5. 比較画面ではSourceとTargetを指定し、
   フォルダー／ファイルの差分確認、同期、ZIP保存などを行えます。


■ キーボード操作

Ctrl + 1
メイン画面へ切り替え

Ctrl + 2
比較画面へ切り替え

Ctrl + 3
Grep画面へ切り替え

メイン画面では上下キーによる検索ヒット移動、
左右キーによる横スクロールに対応しています。

差分表示ではShiftキーと矢印キーを組み合わせた
差分移動操作に対応しています。


■ v3.6.0について

v3.6.0では、v3.5系で追加した比較画面およびGrep画面のタブ化を含め、
検索、比較、同期、ドラッグアウト、キーボード操作などの機能を整理しています。

主な変更内容は次のとおりです。

・比較画面／Grep画面の履歴タブ対応
・チェックしたフォルダー配下を対象とするスコープ検索
・メイン画面のフォルダー／ファイルのドラッグアウト対応
・比較画面からのドラッグアウト対応
・比較対象の選択状態を利用したZIP保存機能の改善
・比較処理用インデックスの事前作成
・ソリューション解析処理の改善
・同期処理失敗時の1回のみの再試行処理
・キーボードショートカットをCtrl + 1 / 2 / 3へ変更
・比較／Grep履歴タブ削除時の確認操作を廃止
・各種UIおよび操作性の改善
・不具合修正


■ 注意事項

大量のファイルを含むフォルダーやネットワーク上のフォルダーでは、
ファイル数、ストレージ性能、ネットワーク環境などによって
走査や検索に時間がかかる場合があります。

同期、ZIP保存などファイルを操作する機能を使用する場合は、
Source / Targetおよび対象ファイルを確認してから実行してください。
