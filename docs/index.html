DesktopIniManager v4

読み取り中心の開発支援ツール

DesktopIniManager（DIM）は、フォルダー／ソリューションの解析、ファイル検索、Scoped Grep、フォルダー比較、DIFF表示、desktop.iniによるフォルダーアイコン管理を統合します。

Read-only by design. DIM自身はファイル内容を編集・保存しません。検索・解析・比較・確認・外部ツールへの受け渡しに徹し、意図しない文字コード、BOM、改行コードなどの変更責務から切り離します。

01 / Main

メイン画面

Targetを起点に物理フォルダー、Visual Studio Solution、検索結果を切り替えます。フォルダーチェックはScoped File Search／Scoped Code Grepの対象指定として共通利用します。

Folder Tree

全チェックON/OFF、反転、折りたたみ／展開、チェック済み表示、表示サイズ変更、フィルターに対応。Targetルート行は固定表示します。

Scoped Operation

チェックしたフォルダー配下だけを検索対象にするScoped File SearchとScoped Code Grepを同じ選択状態から利用できます。

desktop.ini

選択アイコンをチェック済みフォルダーへ設定し、desktop.iniを生成／リセット。.gitignoreへの追加にも対応します。

Drag-out

フォルダーと所属ファイル、または複数選択したファイルをDIMから外部へ直接ドラッグアウトできます。

5 Process Slots

DIM1～DIM5を独立スロットとして管理。In Useは現在、Freeは空き、Openは別プロセスで使用中のスロットを示します。

Batch File Launcher

%d% Directoryフルパス、%f% 選択ファイルのフルパス、%n% ファイル名を引数として渡せます。

Languages

English / 日本語 / 中文（繁體）/ 한국어 の4言語に対応。

Themes

Dark / Light / DIM1～DIM5を切り替え、用途ごとに視覚的に識別できます。

02 / Compare

Developer Differencer

SourceとTargetのフォルダー構造を比較。パス選択時にインデックスを構築し、日時／サイズによる高速な差異判定を行います。

Simple Comparison

通常は更新日時＋サイズで比較。日付比較を外すとサイズのみで判定し、ハッシュ比較までは行いません。

Same Check

通常は直接チェックできないSameファイルを一括でチェック／解除し、同期やZIPへ含められます。

Environment Files

ビルド生成物など環境依存ファイルは基本的に比較から除外。obj / binは個別に表示を切り替えます。

Refresh / Clean

全体更新、選択フォルダー内のみ更新、Solution Cleanに対応します。

03 / Inspect

DIFF VIEW

比較結果のファイルをダブルクリックすると内蔵DIFF VIEWへ。Sourceは黄色枠、Targetは青枠。シンタックスハイライトと中央の差分セクションマップで変更箇所を追跡します。

マージ機能は持たせません。 DIMによる走査・検索・比較・閲覧ではファイル内容を変更せず、編集が必要な場合だけ設定済みの外部エディター／マージツールへ渡します。
04 / Search

Scoped Grep

複数フォルダーを検索スコープとして保持し、チェック状態で対象を選択。正規表現、大文字小文字、単語単位検索に対応します。

Language Profile

対象拡張子をプロファイル化し、テンプレートの追加／削除／編集が可能です。

Code / Document Separation

Code GrepとDocument Grepは完全分離。DocumentはExcel / PDF内部を対象とし、通常Textを含める場合はPlainを選択します。

Result Handling

フィルター、エディター出力、ファイル保存、グループ伸縮、グループヘッダーのドラッグアウト、新規タブ追加に対応。

Editor Integration

ファイル、行番号、列番号を外部エディターへ渡せます。エディター別の起動引数とプリセットを設定できます。
