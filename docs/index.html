DesktopIniManager v4

読み取り中心の開発支援ツール

DesktopIniManager（DIM）は、フォルダー／ソリューションの解析、ファイル検索、Scoped Grep、フォルダー比較、DIFF表示、desktop.iniによるフォルダーアイコン管理を統合します。

Read-only by design. DIM自身はファイル内容を編集・保存しません。検索・解析・比較・確認・外部ツールへの受け渡しに徹し、意図しない文字コード、BOM、改行コードなどの変更責務から切り離します。
Folder Analysis Solution Analysis Scoped File Search Scoped Grep Folder Diff Read-only DIFF
01 / Main

メイン画面

Targetを起点に物理フォルダー、Visual Studio Solution、検索結果を切り替えます。フォルダーチェックはScoped File Search／Scoped Code Grepの対象指定として共通利用します。

Folder Tree

全チェックON/OFF、反転、折りたたみ／展開、チェック済み表示、表示サイズ変更、フィルターに対応。Targetルート行は固定表示します。

Scoped Operation

チェックしたフォルダー配下だけを検索対象にするScoped File SearchとScoped Code Grepを同じ選択状態から利用できます。

desktop.ini

選択アイコンをチェック済みフォルダーへ設定し、desktop.iniを生成／リセット。.gitignoreへの追加にも対応します。

Drag-out

フォルダーと所属ファイル、または複数選択したファイルをDIMから外部へ直接ドラッグアウトできます。

5 Process Slots

DIM1～DIM5を独立スロットとして管理。In Useは現在、Freeは空き、Openは別プロセスで使用中のスロットを示します。

Batch File Launcher

%d% Directoryフルパス、 %f% 選択ファイルのフルパス、 %n% ファイル名を引数として渡せます。

Languages

English / 日本語 / 中文（简体）/ 한국어 の4言語に対応。

Themes

Dark / Light / DIM1～DIM5を切り替え、用途ごとに視覚的に識別できます。

02 / Compare

Developer Differencer

Source と Target のフォルダー構造を比較。パス選択時にインデックスを構築し、日時・容量・ATTR（BOM）・XXH128を個別に指定して比較します。日時・容量・ATTRは有効な項目をそれぞれ判定し、XXH128は先行する判定で差分が確定していないファイルだけを計算します。

Simple Comparison

日時・容量・ATTR（BOM）・XXH128を個別にON／OFFできます。日時・容量・ATTRは独立して判定し、XXH128は先行する有効な項目で差分が確定した場合に省略します。XXH128だけONの場合は、両側に存在するファイルの内容をハッシュ比較します。

Same Check

通常は直接チェックできないSameファイルを一括でチェック／解除し、同期やZIPへ含められます。

Environment Files

ビルド生成物など環境依存ファイルは基本的に比較から除外。obj / binは個別に表示を切り替えます。

Refresh / Clean

全体更新、選択フォルダー内のみ更新、Solution Cleanに対応します。

03 / Inspect

DIFF VIEW

DIFF VIEWはテキスト、画像、アニメーションGIF、動画、音声の比較表示に対応。Sourceを黄色枠、Targetを青枠で区別し、ファイル内容を変更せず確認できます。

マージ機能は持たせません。 DIMによる走査・検索・比較・閲覧ではファイル内容を変更せず、編集が必要な場合だけ設定済みの外部エディター／マージツールへ渡します。

v4.5.6 PreRelease：動画／音声DIFFに左右個別のDelay調整を追加しました。動画では個別音量・ミュートと6段階の再生速度切替に対応し、再生中のシーク操作を安定化。音声では波形カーソルを直接ドラッグしてDelayを調整でき、数値欄・スピナーに反映されます。

音声ファイルの1時間制限を撤廃し、ドラッグ＆ドロップや貼り付けでも長時間音声を扱えるようにしました。差分解析をバッファ付き逐次デコード方式に最適化し、初回の差分表示ON時にバックグラウンドで計算します。解析中はテーマに合わせた待機オーバーレイを表示し、計算結果はキャッシュしてON／OFF切り替えで再利用します。横方向ズームは表示左端を基準に右方向へ拡大・縮小します。

音源リソースの変更箇所を確認するための波形差分表示です。単に2つの波形を並べるだけではなく、デコードしたPCMサンプルを共通の時間軸上で比較し、差異を検出した区間を赤色で描画します。サンプルレートが異なる場合は高い方の時間グリッドに合わせてリサンプリングし、チャンネルの欠落や末尾の長さの差も検出対象にします。これは音声認識・周波数解析などの高度な音声解析ではなく、その手前で音源リソースの差異を可視化する機能です。

上部マップで全体と現在の表示範囲を確認し、ガイド枠をドラッグして表示位置を移動できます。A–B区間のリピート再生、Source／Targetの同期再生と個別音量調整に対応します。再生速度は0.5／0.75／1.0／1.5／1.75／2.0倍の6段階から排他的に選択でき、初期値は1.0倍です。選択中のボタンは明るく、その他は薄く表示されます。

画像DIFF VIEW

BMP／JPEG／PNG／GIF／TIFFの最近傍拡大縮小、ピクセルグリッド、座標・ARGB表示、XOR比較に対応。アニメーションGIFはフレーム選択ができます。

Git difftool

動画DIFF VIEW

MP4動画を左右に並べて表示し、共通の再生・シーク操作でフレームを確認できます。

音声DIFF VIEW

04 / Search

Scoped Grep

複数フォルダーを検索スコープとして保持し、チェック状態で対象を選択。正規表現、大文字小文字、単語単位検索に対応します。

Language Profile

対象拡張子をプロファイル化し、テンプレートの追加／削除／編集が可能です。

Code / Document Separation

Code GrepとDocument Grepは完全分離。DocumentはExcel / PDF内部を対象とし、通常Textを含める場合はPlainを選択します。

Result Handling

フィルター、エディター出力、ファイル保存、グループ伸縮、グループヘッダーのドラッグアウト、新規タブ追加に対応。

Editor Integration

ファイル、行番号、列番号を外部エディターへ渡せます。エディター別の起動引数とプリセットを設定できます。
