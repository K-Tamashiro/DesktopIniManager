# Developer Differencer

ファイル名は旧版からのリンクを維持するため `mft-differencer.md` のままですが、
現在の画面名は **Developer Differencer** です。MFTを直接読みません。
メイン画面・比較・Grepの列挙は `FindFirstFileExW` / `FindNextFileW` を使います。

## 比較

1. メイン画面下部の比較ボタンから開き、Source（左）とTarget（右）を指定します。フォルダーのドロップにも対応します。
2. Compareで双方のメタデータをそれぞれ一回の走査で取得し、相対パスで比較します。走査中は取得済み件数を表示し、キャンセルできます。
3. Same / Diff / Left / Rightで表示を絞り込みます。初期状態は差異・左だけ・右だけがONです。
4. OBJ / BINは初期状態でOFFです。ONにすると該当フォルダーのファイルを表示します。
5. ルート選択では全階層のファイルを名前順に表示し、フォルダー選択では対象を絞ります。
6. Updateは比較一覧にある選択フォルダー直下のファイルを再確認します。新規ファイルの検出にはCompareを使います。

比較はサイズと更新日時（秒単位）で行います。Compare datesをOFFにするとサイズのみで判定します。
内容やハッシュが一致する保証はありません。更新日時が同じでサイズだけ異なる場合は「サイズ差異」と表示します。

## 選択と同期

フォルダーのチェックは表示中の差異種類に適用されます。フィルター変更で隠れた既存のチェックは保持され、
同期の確認件数に含まれます。同一ファイルは閲覧のみで、同期対象にはできません。

Source → Targetまたは逆方向を選び、コピー・上書き・削除件数を確認して実行します。
**送り元にない選択ファイルは、送り先から削除されます。**
対象ファイルをほかのアプリケーションで編集している間は同期を避けてください。

同期は双方のメタデータを確認し、一時ファイルを経由してコピー・置換します。
成功・ロックによるスキップ・失敗をログで確認できます。処理後は再比較します。
フォルダーそのものや空フォルダーの同期・削除、Git履歴操作、マージは行いません。

`.git`、`.vs`、`.vscode` のパス要素は比較・同期から除外します。
ルートの重複・包含や、ルート外への相対パスは拒否します。
リンクを含むツリー全体の安全性を保証するものではありません。
比較対象には実体のある独立したフォルダーを指定してください。

MFTアクセスのための昇格要件はありません。読み取り・書き込みには通常のアクセス権が必要です。
ネットワークやクラウド上の動作はプロバイダー、ファイルの実体、接続状態に依存します。
同期後のサイズ・日時確認はファイル内容の検証を意味しません。

## Diff View

ファイルをダブルクリックすると読み取り専用のDiff Viewを開きます。

- テキスト：行番号、追加・削除・変更の色分け、左右連動スクロール、中央マップ、差分の前後移動。
- 複数行のテキスト選択・コピーでは表示用の行番号を含めません。
- 画像：左右共通倍率、Fit / 100%、連動スクロール。
- 左右それぞれを関連付けアプリで開くか、外部Diffへ送れます。外部編集後は該当ファイルを再確認します。
- BOM、UTF-8、Shift-JISのテキストを読み、容量・行数の大きいファイルやバイナリは外部ツールへ案内します。

## Clean solution

Source / Target配下のソリューションと構成を選んでMSBuild Cleanを実行し、処理後に再比較します。
実行中のDesktopIniManagerを含むソリューションはCleanできません。
本アプリ自身をCleanする場合は、ソリューション外に展開した配布版から起動してください。

## 保存と検証

比較ルートは `%LOCALAPPDATA%\DesktopIniManager\mft-differencer.xml` に保存します。
保存名も旧版との互換性のため維持しています。メイン画面のPhysical / Solutionツリーは
別の `folder-trees.xml` で管理します。同期ログも同じ設定ディレクトリに保存します。

テストプロジェクトは `Tests/DesktopIniManager.DifferencerTests.csproj` です。
テストは実行ファイルの隣に独立したfixtureを作成します。
旧v3.0.0の確認結果は [当時のリリースノート](releases/v3.0.0-DIR.md) を参照してください。
