# DesktopIniManager v3.0.0 — DIR edition

Prepared: 2026-09-13

v3.0.0 completes the .NET 10 DIR edition of DesktopIniManager, including the
workspace/UI refactoring, final interaction improvements, and refreshed screenshots.

## Changes from v2.x

- Acquire the workspace through Windows DIR and use ordinary file-system access
  for Grep and comparison. No raw MFT access or elevation requirement for enumeration.
- Move the Windows desktop application to .NET 10 and distribute a framework-dependent
  Windows x64 package.
- Prepare the saved workspace during the splash screen, with acquisition and
  solution-parsing progress.
- Retain independent Physical, Solution, and Search views and their folder state.
- Finish icon-based controls, compact tree display, selection controls,
  folder drag-and-drop, path histories, and window positioning.
- Preserve Grep scopes across tree branches, remove nested duplicates, and improve
  result filtering, cancellation, and external-editor integration.
- Refine Developer Differencer, folder status icons, selection/filter behavior,
  progress, and the read-only text/image Diff View.
- Support multiline text selection without copying displayed line numbers.
- Remove unused methods and obsolete search/session classes; fix a stale private-field
  access in the folder-tree regression test.
- Update regression tests for deferred WPF bindings, Command actions, and dedicated
  solution icons. Host resources in a test Application so tests never launch the
  production splash or scan the saved workspace.
- Remove duplicate resource keys and unused toolbar state, and declare Windows
  platform support for the .NET 10 application and test build.
- Remove the deleted FastVolumeIndex.Cli project from its solution. The release no
  longer includes mftree.exe.
- Replace README screenshots and documentation for the DIR edition.

## Package

`DesktopIniManager-v3.0.0-DIR-win-x64.zip`

Extract into a new directory and run `DesktopIniManager.exe`. Keep the complete
directory together. Install .NET 10 Desktop Runtime (x64) separately.
The package contains the application EXE, two application DLLs, dependency/runtime
configuration JSON files, README, icon libraries, language files, and documentation.
The .NET runtime is not bundled.

A companion `.zip.sha256` file is generated by `scripts/Build-Release.ps1`.
Build outputs and archives remain outside Git tracking in `release/`; the script
and these notes are tracked with the source.

## Behavior to retain when upgrading

- Comparison uses size and optional whole-second timestamps, not content hashes.
- Checked files missing on the sending side are deleted from the receiving side
  after synchronization confirmation. Hidden selections remain part of the operation.
- Metadata directories `.git`, `.vs`, and `.vscode` are excluded.
- Update rechecks already-listed direct files; Compare discovers added files.
- Cloud/network behavior depends on the storage provider and available file contents.
- The historical library name FastVolumeIndex.Core and persisted comparison-state
  filename mft-differencer.xml remain unchanged.
