# DesktopIniManager v3.2.0 — DIR edition

Prepared: 2026-09-20

v3.2.0 fixes missed folder synchronization and improves Developer Differencer
selection handling for large comparisons.

## Changes from v3.1.0

- Synchronize source-only and target-only folders in either direction, including
  empty folders that previously had no selectable file operation.
- Include eligible descendant folders when checking a parent. Keep folder
  selection separate from file selection so empty folders remain actionable.
- Show Create folder and Delete folder counts in the synchronization confirmation.
  Create parent folders before children and delete children before parents.
  Directory deletion is non-recursive: remaining contents cause a logged failure
  rather than deletion of unselected contents.
- Align folder status icons and selection with the active difference-category
  filters, and apply obj/bin exclusions to folder operations as well as files.
- Reduce repeated work during bulk check/uncheck: defer ancestor notifications,
  refresh selection counts only for the affected branch and its ancestors, and
  skip inclusion checks for unselected files. Difference counts and icons are
  not rebuilt just because selection changed.
- Update the Differencer icon library, README, and screenshots. Include the
  Japanese overview page at `docs/index.html` in the distribution.

Search navigation, solution browsing, Build/Rebuild menus, script execution,
and text-editor exports from v3.1.0 remain available.

## Package and requirements

`DesktopIniManager-v3.2.0-DIR-win-x64.zip`

Extract into a fresh directory and run `DesktopIniManager.exe`. Windows 10/11
x64 and .NET 10 Desktop Runtime x64 are required. The runtime is not bundled.
Keep the DLLs, JSON files, Assets, Languages, README, and docs together.
The application is v3.2.0; the unchanged FastVolumeIndex.Core library is v3.1.0.
MSBuild is needed for Build/Rebuild/Clean; text exports use the configured editor.

## Synchronization notes

Review the direction and operation counts before confirming. Selected items
existing only on the receiving side can be deleted. Category-hidden selections
remain selected; obj/bin exclusions remove excluded selections. Compare again
after files or folders change externally.

File comparison still uses size and optional timestamps, not content hashes.
Network and cloud-backed locations depend on provider availability and permissions.

## Validation and distribution

This package uses the maintainer's prebuilt v3.2.0 Release binaries; packaging
does not rebuild or run tests. The packaging script checks DLL versions, .NET
runtime requirements, and the exact ZIP file list, and produces a `.zip.sha256`
sidecar. No performance timings or automated-test pass results are claimed.

ZIP files and staging folders remain in the Git-ignored `release/` directory.
Release publication and tagging are separate from the local commit.
