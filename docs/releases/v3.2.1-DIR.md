# DesktopIniManager v3.2.1 — DIR edition

Prepared: 2026-09-21

This maintenance release updates icons and makes the chosen synchronization
direction easier to recognize before confirming an operation.

## Changes from v3.2.0

- Refresh the bundled Developer Differencer icon library.
- Display direction-specific icons to the left of Source and Target while the
  synchronization confirmation dialog is open, for both Source to Target and
  Target to Source. Restore normal folder icons when the dialog closes,
  including cancellation.
- Update compact/comfortable tree icons in the main window and Differencer,
  and expand icon loading to include the new entries.
- Refine icon-button sizes, spacing, and transparent backgrounds in light and
  dark themes.

The folder/empty-folder synchronization fixes and bulk-selection improvements
from v3.2.0 are retained. This release does not change synchronization rules.

## Package

`DesktopIniManager-v3.2.1-DIR-win-x64.zip`

Windows 10/11 x64 and .NET 10 Desktop Runtime x64 are required. Extract into a
fresh directory and keep all files together. The application is v3.2.1; the
unchanged FastVolumeIndex.Core library remains v3.1.0. The runtime is not bundled.
The package includes README, release notes, screenshots, and the Japanese
overview page at `docs/index.html`.

Review synchronization direction and operation counts before confirming.
Selected destination-only files and folders can be deleted. File comparison
uses size and optional timestamps rather than content hashes.

## Validation and distribution

Packaging uses the maintainer's Release build without rebuilding or running
tests. The packaging script checks assembly versions, runtime requirements,
and archive contents, then writes a SHA-256 sidecar. No automated-test or
interactive-validation results are claimed here.

ZIPs and staging folders remain outside Git tracking in `release/`.
GitHub publication and release tagging are separate from the local commit.
