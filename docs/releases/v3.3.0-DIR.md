# DesktopIniManager v3.3.0 — DIR edition

Prepared: 2026-09-22

Diff View debugging fixes and display corrections.

## Changes from v3.2.1

- Improve txt/log content detection: recognize BOM-less UTF-16 with a strong
  alternating-NUL pattern and allow terminal/legacy text control characters.
- Check text contents before previous/next navigation and silently skip binary
  files. Opening unsupported files directly from the list still shows a message.
- Restore list selection to the last viewed file when closing Diff View, without
  modifying the SelectedItems collection of a single-selection list.
- Keep line numbers aligned at the top for short files and synchronized with
  scrolling and difference jumps, including blank alignment rows.
- Map differences and the viewport against document height instead of stretching
  a short file across the whole overview. Reflect the selected difference with
  a yellow frame inside the pink viewport frame.
- Fit images and icons initially; retain the manual 100% zoom control.
- Trim common prefixes/suffixes before comparison, remove unnecessary sorting,
  reuse text read for navigation checks, and guard overlapping navigation.

## Package

`DesktopIniManager-v3.3.0-DIR-win-x64.zip`

Requires Windows 10/11 x64 and .NET 10 Desktop Runtime x64. Extract into a fresh
directory and keep all files together. DesktopIniManager is v3.3.0; the unchanged
FastVolumeIndex.Core library remains v3.1.0. The runtime is not bundled.

Includes README, release notes, screenshots, and `docs/index.html`.

## Validation and distribution

Packaged from the maintainer's existing v3.3.0 Release build, without rebuilding
or running automated tests. Regression checks were added to the source harness;
no execution result or performance measurement is claimed for them.
The packaging script checks assembly versions, runtime requirements and archive
contents, and generates a SHA-256 sidecar.

ZIPs and staging directories remain untracked in `release/`, as in previous
releases. Push, GitHub publication and release tagging are left to the maintainer.
