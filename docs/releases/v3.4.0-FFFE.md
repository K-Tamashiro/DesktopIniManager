# DesktopIniManager v3.4.0 — FFFE edition

DesktopIniManager v3.4.0 focuses on improving folder enumeration and analysis performance.

## Highlights

- Accelerated folder enumeration using the native Windows `FindFirstFileExW` / `FindNextFileW` (FFFE) APIs.
- Reused acquired path information to reduce unnecessary file-system access in the Physical Tree, Solution analysis, and related operations.
- Improved startup Physical Tree construction and Solution analysis performance for large development trees.
- Updated Developer Differencer to use FFFE enumeration and reuse file size and last-write timestamps obtained during enumeration for ordinary files.
- Removed the preliminary file-count scan from Developer Differencer so Source and Target are each scanned only once during comparison.
- Added lazy folder expansion for Physical Tree on network/NAS paths, avoiding a full recursive scan during startup.
- Kept common path acquisition feature-neutral: folders such as `obj` and `bin` are handled by feature-specific filters rather than being globally excluded from the shared index.

## Features retained from v3.3.2

- Export selected files from either Source or Target in Developer Differencer to ZIP while preserving their relative path structure.
- Create ZIP archives directly without building a temporary directory tree.
- Select identical files independently using Same ON/OFF.
- Include explicitly selected Same files in ZIP export and synchronization.
- Synchronize empty folders and folders/files that exist on only one side in either direction.

## Network / NAS locations

For network paths, the main Physical Tree uses lazy folder expansion to improve initial display performance and avoid a full recursive startup scan.

Developer Differencer performs a complete comparison of both Source and Target trees. Comparison time on NAS locations therefore depends on network and SMB response performance.

## Requirements

- Windows 10 or Windows 11, x64
- .NET 10 Desktop Runtime (x64)
- Administrator privileges are not required for folder enumeration
