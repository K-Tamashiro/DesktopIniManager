# DesktopIniManager v3.4.1 — FFFE edition

DesktopIniManager v3.4.1 is a maintenance release for the Developer Differencer Same-selection workflow.

## Fixes

- Fixed a regression where operating Same ON/OFF could clear Same files selected in other folders.
- Same selections now accumulate across folders as intended.
- Changing the selected folder resets the Same ON/OFF control without clearing Same selections already made elsewhere.
- Same OFF affects the currently selected folder while the Same category is visible.

## Retained from v3.4.0

- Native Windows FFFE (`FindFirstFileExW` / `FindNextFileW`) folder enumeration.
- Faster Physical Tree and Solution analysis.
- Lazy Physical-tree expansion for network/NAS locations.
- Faster Developer Differencer scanning using enumeration metadata and one scan per side.
- Path-preserving ZIP export from Source or Target.
- Synchronization of selected Same files and folder differences.
