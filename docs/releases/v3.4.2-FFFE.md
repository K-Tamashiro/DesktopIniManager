# DesktopIniManager v3.4.2 — FFFE edition

DesktopIniManager v3.4.2 is a maintenance release that corrects the release binary version and refines Search / Physical / Solution state transitions and file navigation.

## Fixes and changes

- Corrected the packaged application version to v3.4.2.
- Search execution now makes the Search tab authoritative and disables Physical / Solution while the search is active.
- Clearing the search keyword clears the Search tree and file list and re-enables all three tabs without forcing a tab transition.
- With an empty search keyword, selecting Physical or Solution returns to normal mode and disables the empty Search tab.
- Search-hit navigation now selects the owning folder and scrolls off-screen file hits into view.
- In the Physical view, selecting a file selects and reveals its owning folder in the Physical tree.
- A search that returns no files remains on the empty Search view until the keyword is cleared.

## Retained from v3.4.1

- Fixed the Developer Differencer regression where Same selections in other folders could be cleared.
- Same selections accumulate across folders while the Same category is visible.
- Changing folders resets the Same ON/OFF control without clearing selections already made elsewhere.
- Same OFF affects only the currently selected folder while Same is visible.

## Retained from v3.4.0

- Native Windows FFFE (`FindFirstFileExW` / `FindNextFileW`) folder enumeration.
- Faster Physical Tree and Solution analysis.
- Lazy Physical-tree expansion for network/NAS locations.
- Faster Developer Differencer scanning using enumeration metadata and one scan per side.
- Path-preserving ZIP export from Source or Target.
- Synchronization of selected Same files and folder differences.
