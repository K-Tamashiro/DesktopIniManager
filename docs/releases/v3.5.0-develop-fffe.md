# DesktopIniManager v3.5.0-develop-fffe — Pre-release

This pre-release adds persistent result tabs to Developer Differencer and
Scoped Code Grep. It is prepared from `feature/develop-fffe` for evaluation
before a stable v3.5.0 release.

## Developer Differencer

- Each completed comparison creates a dated history tab. Newest tabs appear
  on the left. Tab colors follow the active theme; selected tabs use bold text.
- Switching tabs restores the comparison result, Source / Target roots,
  selected and expanded folders, and display filters.
- The file-list header shows shortened Source / Target names with full paths
  in the tooltip.
- The close button deletes a tab after confirmation. Its enabled state is
  refreshed when comparison work finishes.
- Up to 20 comparison tabs are retained. At the limit, choose whether to
  remove the oldest tab and compare. Declining leaves the current result
  intact and asks you to reduce the tab count to 19 or fewer.
- History is saved and restored across application sessions, including the
  recorded folder state when the original folder is no longer available.

## Scoped Code Grep

- Add search tabs and identify them by the search text.
- Store results, scope folders, language profile, extensions, regular
  expression / case / whole-word options, and the list filter per tab.
- When a tab already has results: **Yes** appends, **No** searches in a new
  tab, and **Cancel** leaves the results unchanged.
- At the 20-tab limit, select an existing tab. **Yes** appends, **No** clears
  only that tab and searches, and **Cancel** lets you choose another tab.
- Save explicitly with icon 95; add tabs with icon 94. Both buttons have
  transparent backgrounds. Tab styling follows the active theme.
- Results are also saved after searching and when closing the window.
  A save error prevents the Grep window from closing silently.
- New messages and tooltips support English, Japanese, Simplified Chinese,
  and Korean.

## History storage and limits

The pre-release also includes Source / Target input-history normalization:
trailing separators and path letter case no longer create duplicate entries,
while drive-root separators are retained. Search text remains case-sensitive
in history. Solution and project configurations now explicitly include x64.

Comparison and Grep each have their own 20-tab limit. History is stored in:

```text
%LOCALAPPDATA%\DesktopIniManager\result-history\comparison.json
%LOCALAPPDATA%\DesktopIniManager\result-history\grep.json
```

Comparison history retains result metadata, not copies of the original file
contents. Opening Diff View reads the files currently on disk. Use the
existing Source / Target ZIP export when file-content backups are needed.

The FFFE enumeration improvements and v3.4.2 workspace navigation fixes are
retained. See the [history guide](../result-history.md) for the detailed workflow.

## Validation and known limitations

- The dedicated history regression suite passes 34 checks covering tab
  ordering, per-tab restoration, both 20-tab policies, append / new-tab
  behavior, deletion-button state, colors, icon availability, and four
  languages. WPF layout rendering is included. The input-history suite also passes 15 checks.
- The broader legacy regression suite is not fully passing: its folder
  selection fixture stops in `DiffFolder.FolderCanSync` with an unset path.
  This pre-release does not claim a clean full-suite result.
- Network and cloud-backed folders still depend on connectivity, permissions,
  and local file availability.

## Package and requirements

- Windows 10 / 11, x64.
- .NET 10 Desktop Runtime (x64), installed separately.
- MSBuild for Build / Rebuild / Clean solution operations.
- Read access to inspected folders and write access for synchronization or
  folder icon changes.

Assets:

```text
DesktopIniManager-v3.5.0-develop-fffe-win-x64.zip
DesktopIniManager-v3.5.0-develop-fffe-win-x64.zip.sha256
```

Extract into a fresh folder and launch `DesktopIniManager.exe`. Keep the
DLLs, runtime JSON files, `Assets`, and `Languages` together. The ZIP also
includes `README.md`, `RELEASE_NOTES.md`, and `docs/`. It contains no bundled
.NET runtime, test fixtures, debug symbols, or user history.
