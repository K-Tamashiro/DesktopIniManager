# DesktopIniManager v3.5.1-develop-fffe — Pre-release

Maintenance update on `feature/develop-fffe` for file-list ordering,
search navigation, and history-menu presentation.

## Changes

- Show files directly under the selected folder before files in descendant
  folders in the main file list and Developer Differencer. Retain distinct
  styling for direct and descendant files (white / gray in the dark theme).
- Sort comparison files by name within each group, with relative path as
  the tie-breaker.
- Keep the selected tree folder when loading its file list. Previous/next
  search-hit navigation still reveals the file's owning folder.
- Replace the colored history-entry delete icon with a simple, theme-colored
  Segoe MDL2 × glyph.
- Add a Beyond Compare 5 external diff command preset.
- Retain persistent comparison/Grep tabs and the existing 20-tab limits.

## Package

```text
DesktopIniManager-v3.5.1-develop-fffe-win-x64.zip
DesktopIniManager-v3.5.1-develop-fffe-win-x64.zip.sha256
```

Requires Windows 10 / 11 x64 and .NET 10 Desktop Runtime (x64).
Extract into a fresh directory and run `DesktopIniManager.exe`, keeping
the accompanying DLLs, JSON files, Assets, and Languages together.

This package uses the user-provided Release build, with file version
3.5.1 and product version 3.5.1-develop-fffe. No rebuild or test rerun was
performed for packaging. The packaging script checks the binary versions,
framework requirements, complete file layout, and ZIP contents, and writes
a SHA-256 checksum. Documentation and assets come from the current tree.
