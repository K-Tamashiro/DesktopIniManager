# DesktopIniManager v3.6.0

## 修正・変更

1. メイン画面のフォルダー右クリック「検索場所に設定」で即座に走査を開始。存在しないフォルダーを拒否し、ルート変更時は旧ツリーの選択・検索結果・インデックスを破棄して検索対象を同期します。ドロップ時もドライブ直下の区切り文字を保持します。
2. 比較画面のSource / Targetで同一パスを再選択しても走査しません。大文字小文字・末尾区切りの違いも同一パスとして扱います。タイトル部分のフォルダーアイコンで明示的に再走査できます。
3. 画面切替をCtrl + 1（メイン）、Ctrl + 2（比較）、Ctrl + 3（GREP）へ変更。文字入力中も利用でき、従来のShiftによる数字キー操作は通常入力に戻ります。Ctrl + Spaceの順送りも継続します。
4. 比較・GREPのタブはダブルクリック、×、全削除、他削除で確認なしに即時削除。処理中の操作制限・履歴上限の確認は継続します。
5. 通常同期の失敗をQueueへ積み、通常処理終了後に1回だけ再実行。再実行成功は成功、再失敗は最終失敗とし、再Queueしません。ファイルとフォルダーの両方に対応します。ロック継続はLOCKEDとして区別し、各操作の最終結果だけを完了件数に集計します。
6. メイン画面のファイルダブルクリックでWindowsの関連付けアプリを起動。選択維持・ドラッグ処理との競合を解消し、クリックされたファイルを開きます。検索結果・リスト・大小アイコン表示が対象です。

## 動作環境・配布

- Windows 10 / 11 x64、.NET 10 Desktop Runtime (x64)。
- 配布名：`DesktopIniManager-v3.6.0-win-x64.zip`。
- SHA-256：ZIP生成時に同名の`.zip.sha256`を作成します。
- ZIPを新しいフォルダーへ展開し、`DesktopIniManager.exe`を起動してください。
- 同期は受信側のファイル・フォルダーを削除する場合があります。方向・対象を確認してください。

## 公開前の検証

今回の修正ではビルド・自動テスト・GUI動作確認を実行していません。作者による[最終確認](v3.6.0-validation.md)の完了後に、修正版バイナリからZIP・SHA-256を生成し、GitHub v3.6.0を正式公開します。旧ビルドのZIPやハッシュは本版の成果物として流用しません。
