# DesktopIniManager v4.0.0

DIM v4 brings five independent workspaces, separate document searching, and a focused read-only diff viewer to its folder analysis, search, comparison, and icon-management tools.

## Highlights

- **Five process slots:** DIM1–DIM5 retain independent settings/history. Launch a free slot or activate an occupied one.
- **Seven restored themes:** Dark, Light, and DIM1–DIM5 theme selections survive restarts.
- **Document Grep:** search Excel (.xls, .xlsx, .xlsm) and PDF contents through Document, separately from Code Grep. Excel hits show [Sheet][Cell] matched content; PDF hits identify their page.
- **Main-window navigation:** fixed single-root tree row, folder-name hit counts/highlighting, list/icon views, and saved column/pane widths.
- **Folder icons:** empty/content states, network/cloud presentation, and a bundled library resolved from the application directory.
- **Comparison workflow:** incremental results, folder-building progress, up to 20 result tabs, explicit rescans, and one-way Source-to-Target selection of an existing same-name folder.
- **DIFF VIEW:** Source-yellow/Target-blue frames, draggable map, and all-lines/differences-only display with filtered-line markers. The last mode is restored per slot.
- **Shortcuts:** Ctrl + Up/Down navigates sections; Ctrl + Left/Right navigates files; Ctrl + 0 toggles display mode. Plain arrows scroll; Shift + wheel retains horizontal scrolling.
- **Scoped search:** append results into file groups, retain tabs, export results, and open an editor at a file/line/column.
- **Structured export:** ZIP checked files or drag the ZIP icon to export their relative folder structure.

## Inspection and explicit file operations

Scanning, searching, comparing, and DIFF VIEW do not edit or merge source contents. Use an external editor/merge tool when needed. Explicit icon management, synchronization, build/Clean, and export operations can write files.

Folder comparison uses size and optional modification time, not content hashes. Document Grep searches extractable text; it does not OCR image-only PDFs.

## Download and upgrade

- Asset: DesktopIniManager-v4.0.0-win-x64.zip
- Checksum: DesktopIniManager-v4.0.0-win-x64.zip.sha256
- Requirements: Windows 10/11 x64 and .NET 10 Desktop Runtime (x64).
- Extract into a fresh directory and run DesktopIniManager.exe. Keep all DLLs, JSON files, Assets, and Languages together, including ExcelDataReader and every bundled PdfPig DLL.
- Settings/history are stored per slot under %LOCALAPPDATA%\DesktopIniManager.
