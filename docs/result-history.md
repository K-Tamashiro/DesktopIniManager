# 比較・Grepの履歴タブ

## Developer Differencer

- 比較が完了すると日時付きのタブを追加します。新しいタブが左側です。
- 配色はテーマに連動し、選択中は太字で強調です。×でそのタブを削除できます。
- タブを切り替えると比較結果、Source / Target、フォルダー選択・展開、表示フィルターを復元します。ヘッダーにはルート名を省略表示し、ツールチップに完全なパスを表示します。
- 最大20件です。21件目は最古のタブを削除して続行するか確認します。断った場合は比較を行わず、不要なタブを削除して19件以下にするよう案内します。
- 履歴は比較時点の一覧・サイズ・更新日時を保存します。元のファイル内容のバックアップではありません。差分ビューを開く場合は現在のファイルを読み込みます。

## Scoped Code Grep

- 追加ボタン（アイコン94）で空の検索タブを作成します。検索後のタブ名は検索文字列です。
- 既に結果があるタブで検索すると、はい＝追記、いいえ＝新規タブで検索、キャンセル＝検索中止です。
- 最大20件です。上限では既存タブを選択して検索します。確認は、はい＝追記、いいえ＝選択タブをクリアして検索、キャンセル＝検索せず別のタブを選択、に切り替わります。
- 保存ボタン（アイコン95）でタブを保存します。検索終了時・ウィンドウを閉じる際にも自動保存します。終了時に保存できなかった場合はウィンドウを閉じずにエラーを表示します。
- 各タブに結果、検索文字列、対象フォルダー、言語プロファイル・拡張子、検索オプション、一覧フィルターを保存します。
- 保存・追加ボタンの背景は透明です。

履歴は `%LOCALAPPDATA%\DesktopIniManager\result-history` 内の `comparison.json` と `grep.json` に保存します。両画面それぞれ最大20件です。追加した案内とツールチップは英語・日本語・中国語（簡体字）・韓国語に対応しています。

## 検証

`DesktopIniManager.DifferencerTests.exe --result-history` で、上限、追記・新規作成、保存・復元、タブ順序、配色、削除ボタンの有効状態、多言語リソースを検証します。テスト用履歴は独立した一時ディレクトリに保存します。

## v3.6.0 の削除操作

比較・GREPとも、タブのダブルクリック、×、右クリックの「全削除」「他削除」は確認なしで即時削除します。GREPで最後のタブを削除した場合は空のタブを1件作成します。処理実行中の削除禁止と、上限到達時の確認は従来どおりです。
